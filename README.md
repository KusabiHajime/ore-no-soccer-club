# 俺のサッカークラブ

NSL（日本サッカーリーグ）から始めて、N1リーグの頂点を目指すサッカークラブ経営シミュレーションです。GMとして監督・選手との契約、移籍、スポンサー、施設、資金のやりくりを担います。

ブラウザで遊べます。インストールは不要です。

## 遊び方

- 公開ページを開き、「タップしてスタート」から新しいクラブを創ります。
- セーブはブラウザに自動で保存されます（3枠）。
- 別の端末へ移すときは、ゲーム内の「セーブファイルに保存」で書き出し、移した先の「セーブファイルから再開」で読み込みます。

## 注意

この作品はフィクションです。登場する人物・団体・リーグ・クラブは架空のものであり、実在のものとは一切関係ありません。クラブ名の地名は実在の地域を使っています。
